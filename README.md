# OLX Marketplace Clone (UA) 🇺🇦

Повноцінний маркетплейс у стилі OLX із можливістю **додавання**, **редагування**, **видалення**, **пошуку**, **фільтрації** та **збереження в обрані**.

## 🌟 Основний функціонал:
1. **Додавання оголошень (+ Подати оголошення):**
   - Заголовок (із підрахунком символів)
   - Категорія (Електроніка, Мода, Авто, Нерухомість тощо)
   - Стан (Новий, Ідеальний, Відмінний, Вживаний)
   - Ціна в грн + чекбокс "Можливий торг"
   - Місто та район (Київ, Львів, Харків, Одеса...)
   - Фото (завантаження файлу з комп'ютера або посилання на фото)
   - Повний опис товару
   - Ім'я продавця та телефон
   - Способи доставки (OLX Доставка, Нова Пошта, Самовивіз)

2. **Керування оголошеннями (CRUD):**
   - **Редагування:** зміна будь-яких параметрів оголошення
   - **Видалення:** модальне вікно підтвердження видалення
   - **Збереження даних:** усі зміни зберігаються у `localStorage` браузера та не зникають після оновлення сторінки

3. **Пошук та фільтри:**
   - Пошук за ключовими словами у реальному часі (у заголовку та описі)
   - Фільтр за категоріями (інтерактивні плашки)
   - Фільтр за містом
   - Фільтр за діапазоном цін (від / до)
   - Фільтр за станом товару
   - Фільтр "Тільки з OLX Доставкою"
   - Сортування: Найновіші, Найдешевші, Найдорожчі

4. **Детальний перегляд оголошення:**
   - Велике фото, повний опис, умови доставки
   - Кнопка «Показати телефон» продавця
   - Інтерактивний чат із продавцем (з автоматичною відповіддю)
   - Швидкі кнопки редагування та видалення прямо з перегляду

5. **Обрані товари (❤️):**
   - Додавання в закладки в 1 клік
   - Лічильник у шапці
   - Вкладка для перегляду лише збережених товарів

---

## 🚀 Як запустити:

### Варіант 1: Пряме відкриття
Просто двічі клацніть на файл `index.html` або перетягніть його в будь-який браузер (Google Chrome, Edge, Firefox).

### Варіант 2: Локальний веб-сервер
У папці проекту відкрийте термінал і виконайте:
```bash
npm start
```
або:
```bash
node server.js
```
Після цього відкрийте посилання: **`http://localhost:3000`**
